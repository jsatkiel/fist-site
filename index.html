Questions

Do I need to know anything about computers?

Not at all. I set everything up and handle changes for you. If you can send a text, you're all set.

Are there hosting fees?

No monthly hosting fee. The only other cost is your web address (like yourbusiness.com), which is about $10 to $20 a year. It's registered in your name, so you always own it.

Can customers pay or book on my site?

Yes. I can add a "Pay now" button or online booking using Stripe, Square or a booking tool you already use. The money goes straight to your account.

What if I already have a website?

If it's outdated, hard to use on phones, or just a Facebook page, I can build you a new one and move your web address over.
